Built for clarity

Accessibility

Large controls, readable language, and more than one way to understand status are core product requirements.

Website support

This static site is built with semantic headings, landmarks, a skip link, visible keyboard focus, text labels, flexible layouts, reduced-motion support, increased-contrast support, and touch targets designed to be at least 44 by 44 points. It uses system fonts and does not require JavaScript for navigation or FAQ disclosure controls.

App accessibility target

The iOS app is being prepared for VoiceOver, Dynamic Type and Larger Text, Voice Control labels, reduced motion, increased contrast, Button Shapes, landscape orientation, and adaptive iPad layouts. Drawing instructions, Clear, purchase status, export outcomes, and errors must be announced without relying on color alone.

Current verification boundary

Automated checks and static review do not replace final assistive-technology testing on signed iOS builds and deployed pages. Only accessibility features actually tested for the submitted version will be selected in Apple’s Accessibility Nutrition Labels.

Tell us about a barrier

Contact admin@onlysignature.app with the page or app screen, device, iOS/browser version, assistive technology, and a description of the barrier. Do not include signature content or private documents.
