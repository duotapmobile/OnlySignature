# Brand Guide

## Position

Only Signature is a focused, calm utility: create signature and initials assets, understand transparency, export cleanly. The brand is not legal-tech, a signing platform, a bank, or an AI handwriting generator.

## Color tokens

| Token           | Value                    | Use                                                 |
| --------------- | ------------------------ | --------------------------------------------------- |
| Primary         | `#133A50`                | Brand/background/action                             |
| Primary dark    | `#0A2433`                | Deep background/shadow edge                         |
| Primary light   | `#D7E7EF`                | Light brand surface                                 |
| White           | `#FFFFFF`                | Text/surface                                        |
| Off-white       | `#F7FAFC`                | Light screen/card                                   |
| Dark text       | `#10212B`                | Text on light                                       |
| Muted text      | `#506572`                | Secondary text after rendered contrast verification |
| Success         | `#176B50`                | Success paired with text/icon                       |
| Warning         | `#8A5A00`                | Warning paired with text/icon                       |
| Destructive     | `#A52828`                | Delete paired with label/confirmation               |
| Frosted border  | `rgba(255,255,255,0.34)` | Decorative glass edge                               |
| Frosted fill    | `rgba(255,255,255,0.18)` | Glass over controlled dark surface                  |
| Shadow          | `rgba(5,25,36,0.28)`     | Restrained depth                                    |
| Focus indicator | `#F5C451`                | Visible focus/keyboard ring                         |

Rendered contrast, Increase Contrast, Reduce Transparency, grayscale, and Smart Invert—not token values alone—control acceptance. Glass receives opaque fallbacks and never carries meaning alone.

## Typography and layout

Apple system sans-serif only for UI, store, website, and legal text. The user’s handwriting is the only script element. Use large semantic headings, readable body text, multiline wrapping, generous spacing, 44-point minimum targets, 56-point dominant actions, rounded corners, and restrained shadows.

## Voice and copy

Direct, plain, calm, and precise. Lead with the task and transparency problem. Prefer `Created on your device. We do not upload it.` after verification. Never use privacy absolutes, legal certification, app-wide lifetime claims, technical alpha jargon in primary UI, competitor/famous-brand references, or claims that JPEG is transparent.

## Icon direction

Opaque dark-teal square; dimensional frosted circular lens; subtle transparency motif within the lens; handwritten stroke on a line; strong category recognition. No pen, pencil, nib, generic white cursive S, transparent icon background, copied competitor composition, or SignNow/Signature Maker trade dress.

Prepare integrated `TRANSPARENT`/`TRANSPARENT EXPORT` and no-text variants. Actual-size shelf testing determines selection; if text is not immediately legible at search/Home/Settings sizes, the no-text variant is mandatory.

## Wordmark

Use system-sans `Only Signature`, dark navy on light or white on dark. Keep brand strings centralized because the working name is not legally cleared.
