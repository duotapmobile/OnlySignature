# Out of Scope

Only Signature deliberately excludes:

- PDF/document upload, scanning, editing, filling, signing, storage, or sending
- signature requests, links, workflows, collaboration, teams, CRM, contracts, or a document manager
- identity verification, KYC, signer authentication, certificates, cryptographic/digital signatures, qualified signatures, notarization, witnesses, audit trails, or acceptance guarantees
- AI-generated or beautified signatures, typed signature fonts, templates, and automatic handwriting substitution
- accounts, login, social login, password settings, cloud sync, developer cloud storage, proprietary backend, Railway, Firebase, or RevenueCat
- subscriptions, advertising, analytics SDKs, behavioral tracking, session replay, remote logging, and remote crash-report uploads
- an app-wide premium flag, lifetime-app unlock, or Restore control that implies consumed artwork can be recreated
- Undo; confirmed selected-slot Clear is the deliberate simple recovery mechanism
- incoming share extensions, shared app groups, Spotlight indexing, and cloud document intake
- SVG, PDF, transparent Photos, or image Copy until each specific truth/privacy/interoperability test passes
- final App Preview capture when it does not improve the product page
- worldwide distribution by default

These exclusions are product and risk controls, not a backlog invitation. A future proposal that crosses them requires new founder authority, architecture/privacy/legal review, updated App Store disclosures, and a documented change to the locked decisions.
