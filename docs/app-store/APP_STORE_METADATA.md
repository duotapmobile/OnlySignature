## Full description

Only Signature creates the reusable signature image you need. Draw a handwritten signature, initials, or both. Preview the exact same drawing on a fictional sample document to see the difference between a white image rectangle and a transparent background.

The app does not ask for your real document. It does not edit PDFs, send signature requests, or manage contracts. Create the asset on your device, then place the exported file in Word, Pages, Canva, Preview, email, or another app that accepts images.

Free export includes full-quality PNG and JPEG files with a white background. Transparent export is available as one purchase for the current signature-and-initials set. It is not a subscription. The same purchased set can be exported again without another payment, and an unused signature or initials slot remains included for later.

Purchased drawings remain saved locally in Only Signature until you delete them or delete the app. Files you already exported remain at the destination you chose. There is no account or developer cloud that can reconstruct deleted artwork.

Supported launch formats are PNG with transparent or white background and JPEG with white background. Only formats and destinations verified in the submitted build are shown.

Only Signature creates an image asset. It does not verify identity, issue a certificate, notarize a document, create an audit trail, provide legal advice, or guarantee that a recipient will accept an image signature. Use only a signature you are authorized to use.
