# App Store Screenshot Plan

## Truth rules

Use actual implemented fixture-mode UI only. No real document, checkerboard comparison, imaginary format/destination, fabricated rating, legal certification, document upload, or alpha in flattened screenshot files. The white/transparent comparison uses the exact same fictional document, drawing, scale, size, placement, and date.

## First-eight story

1. `Your Signature and Initials` — actual implemented drawing UI makes the category visible immediately.
2. `Remove the White Box` — matched comparison; realistic obstruction remains legible at actual store size.
3. `No Editing or Cropping` — actual purchase/form preview without implying upload.
4. `Place It on Any Document` — visual asset placement only; counsel/copy review prevents acceptance implication.
5. `No Login. No Subscription.` — landing/purchase evidence.
6. `We Do Not Upload Your Signature` — use only after final network proof and with no “never leaves” wording.
7. `Choose the Format You Need` — only passing format registry entries.
8. `One Purchase for This Set` — exact scope, included slot, and U.S. fixture price only when approved.

The first three must communicate category, white-box problem, and no-editing benefit without the description. Run a five-second comprehension test at actual display size.

## Current target masters

- iPhone 6.9-inch accepted portrait master selected at capture time from Apple’s current list, such as 1320×2868, 1290×2796, or 1260×2736.
- iPad 13-inch portrait master because iPad is supported, selected from current accepted sizes such as 2064×2752 or 2048×2732.
- One to ten screenshots, `.png`/`.jpg`/`.jpeg`, flattened opaque RGB with no alpha.

Recheck sizes immediately before capture/upload. Layout sources preserve safe text areas and localization expansion.

## Pipeline and evidence

Deterministic fixture data → exact UI capture → source composition → flattened output → dimension/color-mode/alpha validation → source/output hashes → UI-copy/feature drift check. The current 16 masters are deterministic web-rendered implemented-UI composition proofs. Final iOS Simulator capture is Apple-gated and must replace them before upload.

Change only the hypothesis asset set and use Apple-reported conversion/confidence without invented expected lift.

Prepare an audio-free 15–30 second storyboard: draw signature, switch initials, rotate, compare, purchase fixture/sandbox, choose independent formats, export. Final preview is excluded from launch critical path until actual-device footage/poster/readability proves it improves the product page.
