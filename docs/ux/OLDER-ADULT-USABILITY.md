# Older-Adult and Situational Usability

Older adults are not one persona. These walkthroughs test sensory, motor, cognitive, privacy, and time-pressure needs without assuming age determines ability.

## 72-year-old first-time iPhone user

Expected: sees one large headline/action; understands Signature/Initials tabs; finds visible Clear and Back; sees matched white/transparent difference; states that one localized payment covers this set and both slots without subscription; finds free export; returns to a named Saved card.

Failure: asks where to upload a document, believes both slots are mandatory, expects recurring/global access, cannot find free export, or believes deletion is cloud-restorable.

## Low-vision user using very large text

Expected: all copy/actions scale; comparison stacks rather than shrinks; glass becomes opaque/high contrast under settings; selected state is text/shape; no focused control is clipped/covered.

Failure: tiny document labels, indistinguishable truncated formats, color-only status, horizontal page scrolling, or clipped Back/action.

## User with hand tremor

Expected: large responsive canvas, spaced 44-point targets, primary 56-point actions, Clear confirmation defaults to Keep Drawing, optional rotation, duplicate purchase taps blocked.

Residual limitation: no Undo means a single accidental mark can require redraw. Test palm/edge input and reduced precision; never claim universal accommodation.

## Privacy-conscious professional

Expected: no document/account/name required; accurate local/no-upload claim; understands selected destinations may transmit/store; finds Data and Storage/Delete All; receives no certification or “never leaves” promise.

## Rushed user completing a form

Expected: signature-only or initials-only can continue; companion slot remains included; defaults are PNG Transparent when purchased and PNG White when free; direct Files/Share; same purchased set re-exports without paywall.

## Acceptance sessions

Record wrong-path taps, document-upload expectations, mistaken subscription/global/lifetime beliefs, missed free action, included-slot misunderstanding, Back/Clear errors, deletion expectations, format confusion, and time-to-completion. Include first-time iPhone users, low vision/large text, reduced fine-motor precision, privacy-conscious and rushed participants. Material purchase misunderstanding returns price/model to founder authority before release.
