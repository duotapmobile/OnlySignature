## Findings corrected in this pass

- Shared press feedback was scaling quiet links, Back, and raised controls indiscriminately. Quiet controls now use opacity only; raised primary controls compress their tinted elevation without moving or resizing text.
- The gold selected-background dot had weak non-text contrast on pale paper. The selection ring/dot now uses navy; gold remains a decorative accent rather than the only selection affordance.
- The `Looks natural` text measured 3.42:1 on white, below the 4.5:1 requirement for its size. It now uses a darker green; the matching check-icon surface is darkened too.
- Focus presentation had no shared recipe. `FocusPressable` preserves React Native's Pressable primitive, events, refs, disabled behavior, and keyboard handling, adding only a two-point outline: navy on paper, light gold on navy.
- Format and destination dialogs used a fade even with Reduce Motion. They now select `none` under that preference.
- Export selectors remained interactive during preparation. They now expose disabled semantics and cannot change a format while an export action is busy.
- The static browser preview produced React hydration errors on viewport/data-dependent main routes. Web navigation now mounts after a matching server/client hydration snapshot. This follows React's documented [server snapshot contract](https://react.dev/reference/react/useSyncExternalStore#adding-support-for-server-rendering), without suppressing hydration warnings. The subsequent startup correction below additionally gates native navigation and splash release on storage/assets/layout readiness.
- Support diagnostics now use explicit shared text colors and readable line height instead of platform defaults.
- The fictional artwork in capture still used centered placement. Capture now uses its 69-percent signing guide, and sample artwork uses a measured frame with a baseline-aware fit that keeps the full raster inside its bounds. This presentation-only correction does not change finger coordinates, stored strokes, real drawing paths, or exported assets. Three new geometry tests cover signature/initials artwork, short and tall frames, all used guide positions, and invalid measurements.
- Screenshot inspection during that correction caught two regressions before any build: the opening's light ink tint had been left on the measuring View instead of the Image, and centered samples fell back to their intrinsic raster size. Tint is now an explicit Image property and both alignment modes use measured dimensions. Source regressions and rendered artwork-bounds/light-ink checks now cover these paths; a green contrast-only scan was not treated as visual approval.
- Responsive coverage previously omitted landscape Home/confirmation and only examined full-name capture. It now includes five matching landscape sizes, all four capture modes, and the existing initials Skip for Now action. Full-bleed drawing explicitly owns its gesture container instead of inheriting page scrolling.
- Enlarged native text now scrolls the shared header with its content; global errors have a bounded, safe-area-aware scroll region. Source regressions cover those branches, but browser fontScale is fixed at 1 and cannot verify actual iOS Dynamic Type.
- Manual inspection caught excessive iPad-landscape Home whitespace after action-fit checks passed. Home now caps standard-text landscape composition at 440 points and groups benefits with deliberate gaps. A rendered density assertion rejects widely dispersed rows; enlarged text removes the cap instead of shrinking required copy.
- Async inspection found that the export operation overlay could be covered by the native destination Modal. Progress now occupies the dialog's measured guidance area after the shared 300ms delay. Source regressions retain Back and Done; actual native Photos/Share destination execution remains unverified.
- Purchase pricing was hidden while busy, and background choices were still operable. Pricing now remains visible, both choices expose disabled state and ignore input, and fallback controls stay disabled until the operation ends. This does not change product lookup, durable purchase preflight, fulfillment, or storage.
- A rendered busy-state assertion exposed missing checked-state semantics in the browser preview: the installed React Native Web does not translate the native accessibilityState object. FocusPressable now maps checked, expanded, selected, busy, and disabled fields to individual web ARIA properties, preserving native props and explicit caller overrides. The implementation matches installed types and React Native's documented [ARIA state properties](https://reactnative.dev/docs/accessibility#aria-checked); three unit tests cover true, false/mixed, and override behavior.
- Reopening a durable pending/interrupted/finishing purchase could leave a disabled purchase action without a persistent explanation. The shared purchase feedback now derives an informational message from the existing state, using existing app strings. Cancellation remains informational; real failures remain errors. All three purchase-capable routes share the same 14-point scalable normal-flow treatment, polite status/assertive error semantics, and intentional scrolling for long recovery copy. No provider, fulfillment, storage, price, or transaction classification was changed. An initial suspected busy-state contrast defect was disproved: `tone="light"` already means dark text on a light surface, and those colors were retained.
- The first consolidated run after that correction caught the small-phone purchase-error fallback at y=645 with a 44-point height, extending below 375x667. The compact recovery state now reduces selection-card padding/gaps and swatch size instead of shrinking the feedback text or weakening the viewport assertion. The subsequent responsive run passed all five portrait and five landscape sizes, with that fallback at y=608 and height 44. Ready-state and enlarged-text recipes are unchanged. Six new purchase-feedback unit/source regressions cover existing-state messages, cancellation/error tones, non-mutation, fixture authorization, shared semantics, and scoped compact spacing.
